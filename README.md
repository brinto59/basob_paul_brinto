# Dona Ito Portfolio

A minimalist portfolio website for character illustrator Dona Ito, inspired by a split-screen hero layout with terracotta and beige tones.

## Quick Start

Open `index.html` in your browser, or run a local server:

```bash
npx serve .
```

## Structure

- `index.html` — Main page with hero, about, portfolio, and contact sections
- `styles.css` — Layout, typography, and responsive styles
- `script.js` — Contact form feedback
- `assets/hero-illustration.png` — Hero section illustration

## Customization

Replace `assets/hero-illustration.png` with your own artwork. Update copy in `index.html` and adjust colors in the `:root` variables in `styles.css`.
